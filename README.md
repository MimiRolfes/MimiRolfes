## What I can help with

**Web applications.** Full-stack and TypeScript throughout — authentication, roles,
schema, API, offline behaviour, deployment. Including the unglamorous parts: versioned
migrations, validation at the boundaries, tests, and data handling that survives a
privacy review.

**Websites that other people can maintain.** Framer and WordPress when the owner needs
to edit their own content; a hand-built frontend when the site has to do more than
present.

**Design to code.** Figma as the source of truth, implemented faithfully — component
states, responsive behaviour, motion, and accessibility basics rather than an
afterthought.

## How I work

- **Figma first.** If a design exists, it is the reference — I don't invent layout where
  a design is expected.
- **Server-side where it counts.** Authorisation and validation live on the server, not
  in the interface.
- **No privacy theatre.** I build privacy-conscious systems and say plainly what still
  needs a legal or security review. I don't call anything "certified".
- **Tested where it matters.** Money paths, permissions and sync logic get tests; a
  one-line helper does not.
